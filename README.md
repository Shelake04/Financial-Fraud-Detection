# Financial Fraud Detection

A machine learning based financial fraud detection system with an interactive dashboard.

## Project Status

Project setup phase.

The implementation will be developed phase-by-phase using the BankSim dataset.

## Planned Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- SQLite
- Streamlit
- Matplotlib
- Seaborn
- Plotly
- Joblib

Optional future components:
- Apache Kafka
- PySpark Structured Streaming
